DeCovarT reproducibility

Gastruloid GRNs, feature panels, and sensitivity analyses

Author

Bastien Chassagnol

Published

November 2, 2026

This book applies DeCovarT to the Suppinger murine gastruloid resource. It records what is run: the data, the algorithms as implemented, the hyperparameters and their values, the code, the outputs, and which outputs are stale. The reasons behind each choice are in the DeCovarT vignettes; each chapter links to the vignette section that states them and does not restate the theory.

0.1 Aims

  1. Estimate, for each labelled cell type j at each bulk-matched time, the mean \widehat{\boldsymbol{\mu}}_{\cdot j} and the within-type covariance \widehat{\boldsymbol{\Sigma}}_{W,j} of a gene panel, on the linear scale that DeCovarT’s convolution needs. The source is one single-specimen scRNA-seq reference (GSE229513, Section 2.1).
  2. Choose that panel for the purpose: genes whose moments can be estimated in every type and that carry information about the proportions \boldsymbol{p} (Section 3.1).
  3. Plug the moments into DeCovarT and deconvolve the bulk series (GSE229386) where a single-cell reference matches it: the standard-Wnt samples at 48 h, 72 h and 96 h.

The target is a covariance plug-in for the likelihood, not a biologically interpretable gene regulatory network (03-2, target). Indices follow the article: gene g=1,\ldots,G, type j=1,\ldots,J, bulk sample i=1,\ldots,N, cell c, with C_j cells of type j.

0.2 Pipeline

?fig-pipeline lists the nine steps in the order the scripts run them. Steps 2 to 5 are Section 3.1; step 7 is Section 4.1; step 8 is 2.1, three regimes; step 9 is Section 5.1.

0.3 Reading guide

Each chapter is the practice half of a vignette chapter. Read the vignette for the model and the reasons; read the chapter for what is run on Suppinger.

Code in R/ and scripts/ is written to be run from the repository root. Chunks marked eval: false show calls that have not been run in the current state of the repository; the outputs they would produce are listed as missing where it matters.
