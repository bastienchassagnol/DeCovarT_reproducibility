7.1 Contaminating \boldsymbol{\Omega}_{j}

Starting from the fitted sparse precisions (Equation 4.1), apply the misspecification factors described in DeCovarT vignettes/S5-misspecification.qmd:

  1. Observation noise (Gaussian, t_\nu, PLN, contaminated Gaussian)
  2. Missing reference component (0%, 2%, 10%)
  3. Copula / PLN dependence across genes
  4. Spillover between types
  5. Outlier genes
  6. Wrong covariance reference (perturb or subsample the glasso / PLN fit)

Zero-inflated or hurdle observation models belong here, as a contamination of the sampling layer, not as the default GRN (?nte-drop-zico).

7.2 scDesign3 settings for GSE229513

The fitted count simulator of S5, simulator draws reference-like cells whose type-level law is known. On Suppinger it is used to calibrate, not to resample: the cells of one specimen series are not biological replicates (Note 3.1).

Factors of the list above that the simulator serves:

  • 1, observation noise: negative-binomial cells replace the Gaussian law; pseudo-bulks are sums of simulated cells at known \boldsymbol{p}.
  • 2, missing component: simulate every type and leave one out of the signature.
  • 3, copula dependence: swap the plug-in correlation for an equicorrelated or a Clayton copula, margins fixed.
  • 6, wrong covariance reference: generate with the \widehat{\boldsymbol{\Sigma}}_{j} of one estimator or time, and fit DeCovarT with another.

Spillover (4) and outlier genes (5) are added after generation; the simulator plays no part in them.

# Not run. scDesign3 is not in renv.lock. Function and argument names
# follow the scDesign3 tutorial (modular interface) and must be checked
# against the installed version before use.
# sce: SingleCellExperiment of one time slot, raw UMI counts of the
#   selected panel, culture-stress labels removed; colData holds
#   cell_type and log_s (log size factor).
# sigma_plugin: named list, one G x G plug-in covariance per cell type.
dat <- scDesign3::construct_data(
  sce = sce, assay_use = "counts", celltype = "cell_type",
  pseudotime = NULL, spatial = NULL, other_covariates = "log_s",
  corr_by = "cell_type"
)
marginals <- scDesign3::fit_marginal(
  data = dat, predictor = "gene",
  mu_formula = "cell_type + offset(log_s)",
  sigma_formula = "cell_type",
  family_use = "nb", n_cores = 2, usebam = FALSE
)
para <- scDesign3::extract_para(
  sce = sce, marginal_list = marginals, n_cores = 2,
  family_use = "nb", new_covariate = dat$newCovariate, data = dat$dat
)
# Known dependence: the correlation of each plug-in covariance.
copula_known <- lapply(sigma_plugin, stats::cov2cor)
cells_sim <- scDesign3::simu_new(
  sce = sce, mean_mat = para$mean_mat, sigma_mat = para$sigma_mat,
  zero_mat = para$zero_mat, copula_list = copula_known,
  n_cores = 2, family_use = "nb", input_data = dat$dat,
  new_covariate = dat$newCovariate
)

7.3 Signature size and selection threshold

S5i, signature size states the hypothesis: accuracy rises with the number of genes, reaches a plateau, then falls once uninformative genes or genes inconsistent between bulk and single-cell libraries enter the panel. Every chapter of this book so far uses one panel, the top n_genes_global = 500 of the legacy type-equal SCTransform ratio (legacy type-equal ratio, Section 3.6). This section plans the sweep that tests the hypothesis on GSE229513. It has not been run.

Design choices:

  • Source of genes. The 500-gene export data/intermediate/equal_type_top500_by_time.rds cannot supply panels larger than 500. The sweep reads the allow-list object data/intermediate/suppinger_sct_allowlist_seurat.rds and the full rank table, then subsets genes per panel size.
  • Truth. Within each type, cells are split at random into a reference half and a pseudo-bulk half. The rank, the mean and the covariance use the reference half only; pseudo-bulks are sums of cells of the other half at known numbers per type. Bulk and reference cells are then disjoint, the condition under which a within-type variance can matter (S5, ReDeconv). Both halves come from one specimen series, so the pseudo-bulks carry no platform bias and no between-specimen variation (Note 3.1).
  • Platform-inconsistent genes. The pseudo-bulks cannot reveal them. The real standard-Wnt bulks of GSE229386 enter through the bulk consistency filter: the sweep is repeated on the panels with the flagged genes removed, and on the real bulks the change of \hat{\boldsymbol{p}} with panel size is reported, since no truth exists there.
  • Scale. Means, covariances and pseudo-bulks use raw UMI counts, so a pseudo-bulk is an exact sum of the cell profiles. The size-factor scale of Section 4.1.1 is a second arm.
  • Metrics. DeCovarT::compute_benchmark_metrics() with the true cell fractions: total variation and RMSE per bulk (regression$global), and per-type correlation and error (regression$cell_type). For the real bulks, the total variation between \hat{\boldsymbol{p}} at each size and at 500 genes.

The covariance has G(G+1)/2 entries per type. Above the number of reference cells of a type the sample covariance is singular, and only the shrinkage estimate of Section 4.2.1 is defined; the closed-form intensity is used in the sweep rather than cross-validation, to keep the cost linear in the number of panels.

# Not run. Function names and arguments follow R/02_02_stats_cross_cell.R,
# R/03_01_stats_covariance_estimation.R and the DeCovarT reference.
# Culture-stress labels are removed first, as in
# scripts/01_03_export_equal_type_seurat.R.
source("R/02_00_utils.R")
source("R/02_01_stats_quality_control.R")
source("R/02_02_stats_cross_cell.R")
source("R/03_01_stats_covariance_estimation.R")

seu <- readRDS("data/intermediate/suppinger_sct_allowlist_seurat.rds")
ranks <- utils::read.csv(
  "output/naive_marker_selection/tables/ranks_global_equal_type.csv"
)
panel_sizes <- c(50L, 100L, 200L, 500L, 1000L, 2000L)
bh_levels <- c(0.001, 0.01, 0.05, 0.2)
time_level <- "48h"
n_bulk <- 100L
n_cells_bulk <- 500L

counts <- assay_matrix(seu, "RNA", "counts")
in_slot <- seu$time_point == time_level # & !culture-stress label
x <- as.matrix(counts[, in_slot])
cell_type <- droplevels(factor(seu$celltypeannotation[in_slot]))
lib <- 10^seu$log_umi[in_slot]
types <- levels(cell_type)

# Disjoint halves within each type: 1 = reference, 2 = pseudo-bulk.
half <- withr::with_seed(20261101, {
  stats::ave(
    seq_along(cell_type),
    cell_type,
    FUN = function(i) sample(rep_len(1:2, length(i)))
  )
})
ref <- half == 1L

# Rank A: legacy type-equal ratio of the current panel (computed on all
# cells of the slot; rank B below is the leakage-free one).
rank_a <- ranks[ranks$time_point == time_level & !is.na(ranks$rank), ]
rank_a <- rank_a$gene[order(rank_a$rank)]

# Rank B: omnibus rank on the reference half; fdr = 1 keeps every gene
# so that each BH level is a filter of one fit.
omni <- rank_genes_omnibus(
  x[, ref],
  cell_type[ref],
  size_factors = lib[ref] / stats::median(lib[ref]),
  fdr = 1,
  n_select = max(panel_sizes)
)
omni <- omni[!is.na(omni$rank), ]
rank_b <- lapply(bh_levels, function(level) {
  gated <- omni[omni$adj_pval <= level, ]
  gated$gene[order(gated$rank)]
})
names(rank_b) <- paste0("omnibus_fdr_", bh_levels)

# Pseudo-bulks at known cell numbers, from the pseudo-bulk half.
pseudo <- withr::with_seed(20261102, {
  lapply(seq_len(n_bulk), function(b) {
    w <- stats::rgamma(length(types), shape = 2)
    m <- stats::rmultinom(1L, n_cells_bulk, prob = w / sum(w))[, 1L]
    cells <- unlist(lapply(seq_along(types), function(j) {
      pool <- which(!ref & cell_type == types[j])
      pool[sample.int(length(pool), m[j], replace = TRUE)]
    }))
    list(y = rowSums(x[, cells, drop = FALSE]), p = m / sum(m))
  })
})

fit_panel <- function(genes) {
  mu <- vapply(
    types,
    function(j) rowMeans(x[genes, ref & cell_type == j, drop = FALSE]),
    numeric(length(genes))
  )
  sigma <- vapply(
    types,
    function(j) {
      xj <- t(x[genes, ref & cell_type == j, drop = FALSE])
      fit_cov_shrinkage(xj, lambda = shrinkage_lambda_closed_form(xj))$sigma
    },
    matrix(0, length(genes), length(genes))
  )
  scores <- lapply(pseudo, function(pb) {
    y <- pb$y[genes]
    p_nnls <- DeCovarT::deconvolute_ratios_nnls(y, mu)
    p_dcv <- DeCovarT::deconvolute_single_cell(y, mu, sigma)$p
    rbind(
      cbind(
        method = "nnls",
        DeCovarT::compute_benchmark_metrics(
          y, mu, estimated_p = p_nnls, true_ratios = pb$p
        )$regression$global
      ),
      cbind(
        method = "decovart_newton",
        DeCovarT::compute_benchmark_metrics(
          y, mu, estimated_p = p_dcv, true_ratios = pb$p
        )$regression$global
      )
    )
  })
  do.call(rbind, scores)
}

rank_lists <- c(list(type_equal_ratio = rank_a), rank_b)
sweep <- do.call(rbind, lapply(names(rank_lists), function(r) {
  do.call(rbind, lapply(panel_sizes, function(n) {
    genes <- utils::head(rank_lists[[r]], n)
    if (length(genes) < n) {
      return(NULL) # the gate passes fewer genes than requested
    }
    cbind(rank = r, n_genes_global = n, fit_panel(genes))
  }))
}))

Three outcomes would bear on the hypothesis. A rise and a plateau in both methods, with no decline up to 2000 genes, says that the panel of 500 is not too large for the pseudo-bulks. A decline that disappears after the bulk consistency filter points to platform-inconsistent genes, which only the real bulks can show. A decline in DeCovarT alone, present already on pseudo-bulks, points to the covariance estimate rather than to the genes.

7.4 A paired bulk and single-cell split

The Suppinger score compares a deconvolution with the composition of a single-cell reference from the same time. That reference is not a split of the bulk. An aliquot is a physical split of one specimen, so the bulk library and the single-cell library measure the same material. Four constraints decide whether a published set can carry that comparison.

  • Real bulk and real single-cell counts come from the same specimen, or from a physical split of one suspension.
  • Sample identifiers can be traced from the bulk to the single-cell library.
  • A deconvolution of that pair has been published.
  • Where the only available truth would be the single-cell recovery itself, an independent count (FACS, imaging or histology) is required.

Three sets meet the first three constraints. Citekeys for these papers are not in the bibliography, so each is named with its DOI.

Dong and colleagues (10.1093/bib/bbz166) split a mouse mammary suspension (GEO GSE136148). SCDC, which is already a comparator in this benchmark, was published on that split. Two animals, and the reported truth is the single-cell recovery.

Guo and colleagues (10.1101/gr.278822.123) profiled healthy retina from 24 specimens, taking bulk and single-cell nuclei from the same suspension. DeMixSC, already a comparator here, was published on that series. The bulk accessions are GSE175937.

Dai and colleagues (10.1126/sciadv.adh2588) deconvolved the forebrain organoids of Jourdon and colleagues (10.1038/s41593-023-01399-0). About 60 samples are reported at TD0, TD30 and TD60. A preparation may pool organoids, so a sample is not always one organoid. Access is NIMH Data Archive study 1482.

He and colleagues (10.1038/s41586-020-2536-x) and the BEDwARS analysis of Ghaffari and colleagues (10.1186/s13059-023-03007-7) are not split aliquots: the bulk and the single-cell profiles are not a physical division of one specimen.
